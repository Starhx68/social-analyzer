4.4. 补贴资格数据核销(2026版)
补贴资格数据核销（2026年活动数据报送），单个批次最大1条，如上送网络超时可进行重试，重复上送或其他校验错误将在响
应errorData中提示。 处理异常的情况：响应码为021004时，整批可部分处理成功，部分处理失败，成功的不需要再次上送，对
于失败或者重复的，根据订单号人工介入处理。

HTTP(S) + JSON
4.4.2. 接口地址
