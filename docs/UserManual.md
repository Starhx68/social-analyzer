# 国补订单资料上传系统 - 用户操作手册 (User Manual)

## 1. 文档概述

本文档旨在为“国补订单资料上传系统”的用户提供详细的操作指导。系统分为**移动端**（主要供现场人员进行资料采集与上传）和**电脑端**（主要供后台人员进行订单管理与资料审核）。

> **提示**: 文档中包含图片占位符，建议管理员截图系统界面并替换到 `docs/images/` 目录下，以获得最佳阅读体验。

---

## 2. 移动端操作指南 (Mobile)

移动端设计简洁，专注于快速检索订单和上传证明材料。

### 2.1 登录系统

1. **访问**: 使用手机浏览器或微信扫描管理员提供的二维码/链接。
2. **界面**:
   ![移动端登录界面](images/mobile_login.png)
3. **操作**: 输入分配的用户名和密码，点击“登录”。

### 2.2 订单查询

登录成功后进入首页，您可以通过以下两种方式找到需要处理的订单：

![移动端首页查询](images/mobile_home_search.png)

1. **扫码查询 (推荐)**:
   - 点击搜索框右侧的 **[📷 相机图标]**。
   - 允许浏览器访问相机权限。
   - 对准订单上的条形码、二维码或订单号数字进行拍摄。
   - 系统识别成功后会自动填入订单号并搜索。
   - *注: 如遇识别无反应，请尝试调整距离或光线。*
2. **手动输入**:
   - 在搜索框直接输入完整的订单号、客户姓名或手机号。
   - 点击键盘上的“搜索”或输入框旁的图标。

### 2.3 资料上传

查询并点击订单后，进入资料上传页面。系统会根据订单类型（家电/3C数码/家装/适老化）自动显示需要上传的材料清单。

![资料上传页面概览](images/mobile_upload_overview.png)

#### 2.3.1 核心步骤

1. **浏览清单**: 查看页面列出的所有上传项。
   - `<span style="color:red">`* 红色星号标记为**必填项**。
   - 无标记为选填项。
2. **上传图片**:
   - 点击“点击上传”区域。
   - 选择“拍照”或从“相册”选择图片。
   - **注意**: 图片大小限制为 50MB，系统会自动压缩。建议保持清晰度以便审核。
3. **智能识别 (OCR)**:
   - **SN码/IMEI码**: 上传包含条码的图片后，系统会自动尝试识别号码并填入对应输入框。
   - **发票**: 上传发票照片后，系统会自动提取发票代码、号码等信息。
   - *检查*: 识别完成后，请务必核对输入框中的数字是否与图片一致，如有误可直接点击输入框修改。

#### 2.3.2 3C数码类特别说明

对于手机、平板等3C数码类订单，流程略有不同：

- **物流单据 (必填)**: 请优先上传签收物流照片。
- **IMEI信息**: 需上传IMEI照片，系统会自动提取 IMEI1 和 IMEI2。

### 2.4 保存与提交

页面底部有两个按钮：

1. **保存资料**: 仅保存当前已上传的图片和录入的号码，**不触发审核**。适用于资料未收集齐，需要稍后继续补充的场景。
2. **提交审核**:
   - 点击后系统会进行完整性校验（检查必填项、SN码是否录入）。
   - 校验通过后，订单状态变为 **“审核中”**。
   - *注意*: “审核中”状态下无法修改资料。

## 3. 电脑端操作指南 (PC)

电脑端提供完整的后台管理功能，建议使用 Chrome 浏览器访问。

### 3.1 订单管理

进入 **“订单列表”** 页面：

![PC端订单列表](images/pc_order_list.png)

- **状态筛选**: 页面顶部提供状态标签（待上传、审核中、审核驳回、已完成），点击可快速筛选对应状态的订单。
- **综合搜索**: 在搜索框输入关键词（订单号/手机号/商品名）进行检索。
- **操作栏**:
  - **详情**: 查看订单的Oracle原始数据及所有关联信息。
  - **上传资料**: 电脑端也支持上传资料，操作方式与移动端类似。

### 3.2 审核流程 (仅审核员)

审核员在 **“审核管理”** 页面处理待审核订单。

![审核界面](images/pc_audit_interface.png)

1. **领取任务**: 点击状态为“审核中”的订单进入审核界面。
2. **双屏核对**:
   - **左侧 (图片区)**: 显示用户上传的所有图片。支持放大、旋转、切换图片。
   - **右侧 (数据区)**: 显示订单原始信息及OCR识别出的数据（SN码、发票信息）。
3. **审核决议**:
   - **✅ 通过**: 确认资料齐全、信息一致。订单状态流转为“已完成”。
   - **❌ 驳回**: 资料有误或缺失。点击驳回后**必须填写驳回原因**。
     - 驳回原因会直接显示在移动端，指导用户重新上传。
     - 订单状态回退为“审核驳回”。

### 3.3 常见状态与含义

| 状态               | 含义                   | 操作建议                                 |
| :----------------- | :--------------------- | :--------------------------------------- |
| **待上传**   | 初始状态，或资料被清空 | 请前往上传资料                           |
| **上传中**   | 已有部分资料，但未提交 | 请补全资料并点击“提交审核”             |
| **审核中**   | 已提交，等待后台处理   | 资料已锁定，请耐心等待                   |
| **审核驳回** | 审核不通过             | **请查看驳回原因**，修改后重新提交 |
| **已完成**   | 审核通过               | 流程结束，无需操作                       |

## 4. 常见问题解答 (FAQ)

**Q: 拍照上传时提示“图片上传失败”或“文件过大”？**
A: 系统已优化支持大图上传（最高50MB）。如果仍失败，可能是网络不稳定。建议切换到 Wi-Fi 环境，或在相机设置中稍微调低分辨率。

**Q: SN码识别错误怎么办？**
A: OCR识别可能受光线、角度影响。请直接点击识别结果的输入框，手动修改为正确的号码即可。

**Q: 为什么找不到“提交审核”按钮？**
A: 请确认是否在移动端“资料上传”页面的最底部。如果订单状态已经是“审核中”或“已完成”，该按钮会隐藏。

**Q: 审核驳回后，只需要上传缺少的图片吗？**
A: 不需要重新上传所有图片。旧图片会保留，您只需删除不合格的图片，上传新的，或补充缺少的图片，然后再次点击“提交审核”即可。
